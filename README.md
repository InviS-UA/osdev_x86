# osdev_x86
A hobby 16bit operating system
# How to build this?
requirement tools: build-essential, nasm, qemu-system-x86, mtools, dosfstools, gcc-ia16-elf

Installing gcc-ia16-elf:
    $ sudo add-apt-repository ppa:tkchia/build-ia16
    $ sudo apt-get update
    $ sudo apt-get install gcc-ia16-elf

Clone this repo

Type make into terminal to build and make run
